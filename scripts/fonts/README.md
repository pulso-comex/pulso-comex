# Tipografías para las imágenes de redes

Las usa `scripts/og_images.py` para dibujar las tarjetas de `img/og/`. Son recortes (solo caracteres latinos) de:

- **Source Serif 4** (Adobe), peso Bold — títulos y marca.
- **IBM Plex Sans** (IBM), pesos Regular y SemiBold — rótulos.
- **IBM Plex Mono** (IBM), peso Medium — dato clave.

Las tres se distribuyen con la licencia SIL Open Font License 1.1 (texto en `OFL.txt`), que permite usarlas, recortarlas y redistribuirlas junto al proyecto.
